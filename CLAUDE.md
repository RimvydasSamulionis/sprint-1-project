# Document Management App

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Running the app
- This project runs locally only.
- Everything runs on localhost:3000.
- Do not suggest deployment, hosting, Docker, Vercel, AWS, or cloud infrastructure unless explicitly asked.

## Conventions
- Keep the application simple.
- Prefer modifying existing files over creating new files.
- Don’t add any external libraries or packages without asking first.
- The app has two routes: `/` (home page) and `/workspace` (document management workspace).
- Do not add further routes unless explicitly requested.
- Do not add any new pages beyond these two unless explicitly requested.
- Use TypeScript strict typing.
- Follow existing project structure and naming conventions.

## Before making changes
- First explain the proposed approach briefly.
- If multiple approaches are possible, recommend one and explain why.
- Ask before making major architectural changes.

## Code style
- Write clear, beginner-friendly code.
- Prefer readability over cleverness.
- Add comments only when they improve understanding.
- Avoid unnecessary abstraction.

## Do not
- Add npm dependencies.
- Use eval().
- Introduce global state management libraries.
- Refactor unrelated code.
- Delete existing functionality unless explicitly requested.

## When uncertain
- Ask a question instead of guessing.
